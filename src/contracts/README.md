# Ortak sözleşmeler
Koordinasyon: backend sahibi; etkilenen alan sahipleri birlikte inceler.
health.ts uygulanmış HTTP yanıtıdır; docs/openapi.yaml ile birlikte değişir.
learning.ts, POST /api/learning/plan istek/yanıt ve güvenli hata DTO'larını taşır; docs/API.md ve docs/openapi.yaml ile birlikte değişir. Başlangıç planı yalnızca mock fixture'ıdır.
Koordinasyon ekibi: Mete, Burak, Asude. Ortak sözleşmelerde görev başına tek yürütücü; etkilenen ekipler incelemeye katılır.
Buraya React, Next, env, DB driver veya sağlayıcı SDK'sı eklemeyin.
